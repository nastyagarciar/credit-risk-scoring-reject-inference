# Data

The original source is `DatosPractica_Scoring.xlsx`, supplied as academic coursework material.

It is **not redistributed** in this public portfolio repository because the assignment did not provide a public redistribution license.

The workbook contains three applicant populations:

- **Accepted (`Cardhldr = 1`)**: observed default outcome is available.
- **Rejected (`Cardhldr = 0`)**: default outcome is unobserved.
- **New applicants (`Cardhldr = NA`)**: 34 applicants with IDs 1286–1319 to be scored.

To reproduce the notebook, place the original workbook in this directory as:

`data/DatosPractica_Scoring.xlsx`
